# Fotos dos membros

1. Coloque aqui a foto de cada membro, com o nome do arquivo igual ao campo `photo`
   em `src/app/data/content.ts` (ex.: `03.jpg`, `05.png`).
2. Rode `npm run fotos` no terminal: as fotos viram `.webp` leves e os originais
   vão para a pasta `originais/` (o site não usa essa pasta).

- Formatos aceitos: .jpg, .jpeg, .png, .webp
- Ideal: foto de perto, em pé (retrato), com o rosto na parte de cima
